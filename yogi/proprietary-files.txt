# eSIM. Two separate things. EuiccSupportPixel is the low-level half: eUICC firmware
# and applet updates, its own privapp allowlist, and a malibu overlay. It runs with or
# without GMS. EuiccGoogle is the LPA, and it only works with GMS, which is what
# EuiccPolicy gates it on. The malibu overlay moves to product/app because extract_utils
# only has package rules for app and priv-app, and an apk cannot go through
# PRODUCT_COPY_FILES. It is a static rro, so it applies from anywhere on a system
# partition, and stock already ships the other euicc overlay out of priv-app.

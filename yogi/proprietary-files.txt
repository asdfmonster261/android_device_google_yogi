# IMS, which is what makes voice calls work. Nothing here implemented
# android.telephony.ims.ImsService, so the framework never registered IMS: on a VoLTE
# network that leaves SMS and data working and voice calls failing to connect, because
# SMS rides the CS domain and needs no IMS. ImsStack and Iwlan are built from source
# (packages/modules/ImsStack, packages/services/Iwlan) and bring their own permissions
# and sysconfig with them, so they are named in PRODUCT_PACKAGES rather than listed
# here. These two have no source in the tree. qns is what
# config_qualified_networks_service_package already points at.
#
# Both are platform-signed, so they re-sign with our key rather than needing PRESIGNED.
# The permissions file is load-bearing: a priv-app holding a signature|privileged
# permission that nothing allowlists throws out of system_server at boot.
system_ext/etc/permissions/com.android.qns.xml

system_ext/priv-app/PixelImsMediaService/PixelImsMediaService.apk
system_ext/priv-app/PixelQualifiedNetworksService/PixelQualifiedNetworksService.apk

# The side fingerprint sensor overlay. yogi reads fingerprints from the power button, and
# this is what tells Settings so: the per-stage guidance strings, the lottie animations
# showing which way to move, and the message timing that stops it repeating one line. The
# HAL enrolls fine without it (samples count down normally), the enrollment just gives no
# useful direction. Moved to product/app because extract_utils has package rules for app
# and priv-app only; it is a static rro, so it applies from anywhere on a system partition.
product/overlay/SfpsOverlay.apk:product/app/SfpsOverlay/SfpsOverlay.apk

# Carrier config. The framework loads it from the package named by
# platform_carrier_config_package, which is com.google.android.carrier, and with that
# package absent nothing is applied at all: carrier_config_applied_bool stays false and
# every value falls back to its AOSP default. carrier_volte_available_bool defaults to
# false, so the framework will not attempt IMS voice registration and calls do not
# connect even with a working ImsService and a network advertising VoPS. PRESIGNED
# because it is signed with Google's key and carrier privilege rules are certificate
# based, so re-signing would change what the SIM grants it.
product/etc/sysconfig/preinstalled-packages-pixel-carrier.xml
product/priv-app/CarrierSettings/CarrierSettings.apk;PRESIGNED

# eSIM. Two separate things. EuiccSupportPixel is the low-level half: eUICC firmware
